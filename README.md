**_# OnlineShoppingSystem_**

**Coursework Description**

_**Objectives**_

> This coursework aims to assess the knowledge and skills I have acquired about object-oriented programming during the module. I have been asked to implement a program where objects interact to fulfil a set of functional requirements.

_**Analyse the problem statement**_

> In this assignment, the first task that I should perform is a careful analysis of the problem statement in order to make sure I have all the information to elaborate a solution.

_**Problem description and requirement statement**_

> I am required to develop a program to manage an online shopping system.

> I should implement a console system from where the manager can add new products, delete them if needed, and print and save them as described in detail in the coursework description.

> Finally, I should implement a Graphical User Interface (GUI) from where a user can select different products, add them to the shopping cart and visualise the final price, etc., as described in the coursework description.
